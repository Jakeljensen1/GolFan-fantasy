GolFan is a full‑stack fantasy golf application built with the MERN stack: MongoDB, Express, React, and Node.js and designed on the motto of “Play. Predict. Compete.” The platform gives users an engaging way to interact with professional golf by building lineups, tracking scoring, and competing with friends, and tracking their results. Each tournament includes its own field, scoring logic, and results, allowing users to follow events from lineup creation all the way through final standings. The app also includes personalized profile statistics, lineup history, and a clean, responsive UI that mirrors the feel of modern fantasy sports platforms.

On the backend, GolFan follows a clear MVC architecture, keeping the codebase organized and scalable. Models define the structure of users, golfers, tournaments, results, entries, and lineups in MongoDB. Controllers handle logic, including authentication, golfData API syncing, fantasy scoring, and leaderboard generation. Routes expose RESTful API endpoints consumed by the frontend. The React frontend serves as the “View” layer, rendering pages like TournamentPage, ProfilePage, and LeaderboardPage, while using service modules to communicate with the Express API. This separation of concerns ensures maintainability and makes it easy to extend the app with new features. Many feature that I will be implementing in the future.

Together, the MERN stack and MVC pattern give GolFan a strong architectural foundation, enabling smooth data flow from database to UI and delivering a polished fantasy golf experience. Whether users are building lineups, checking leaderboards, or reviewing their personal stats, GolFan provides a seamless way to compete and enjoy the sport.

In the future, I plan on applying a more "live" feel to the app. It currently only runs off of admin syncs from external APIs. I also intend to add a league setting for the committed fantasy players that would like to play in a year long league with friends or with anyone.
